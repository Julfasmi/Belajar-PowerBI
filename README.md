## 📌 Overview

This repository contains a sales analysis dashboard developed using **Microsoft Power BI**.

The dashboard is designed to transform sales data into an interactive analytical tool that allows users to explore overall performance, analyze products and branches, and inspect detailed data.

The dashboard is organized into several analytical sections, allowing users to move from a high-level overview to more detailed analysis.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Build an interactive sales dashboard using Power BI.
- Transform sales data into meaningful business information.
- Monitor sales performance through key metrics and visualizations.
- Analyze product performance.
- Compare branch performance.
- Provide access to detailed sales data.
- Practice data modeling and DAX in Power BI.
- Present analytical information through effective data visualization.
